# Bookmarks Widget

The **Bookmarks** widget (`type: bookmarks`) provides a touch-friendly web application and URL launcher with automatic domain favicon fetching, instant search, drag-and-drop reordering, alphabetical auto-sorting, and browser bookmark importing.

---

## Features

- **Personal Bookmarks**: Each household member can curate their own bookmark list.
- **Auto-Derived Favicons**: Automatically extracts high-resolution favicons from target domains (or accepts custom icon URLs).
- **Direct Launching**: Tap any icon to open the web service in a new tab.
- **Search Capability**: Real-time filtering by title or URL directly from the detail view.
- **Drag-and-Drop Reordering**: Rearrange bookmark links using intuitive drag handles or accessible up/down controls.
- **Alphabetical Sorting**: Instantly sort bookmarks A–Z or Z–A in the editor or view mode.
- **Bookmark File & Service Import**: Import bookmarks from HTML export files (Chrome, Firefox, Safari, Edge, Raindrop, Pinboard, Shaarli, etc.), Chromium JSON, generic JSON, and CSV files with options to append to or replace existing links.

---

## Managing Bookmarks

1. Tap the **Bookmarks** tile to open the detail view.
2. Tap **Edit bookmarks**.
3. Customize your links:
   - **Add**: Tap **+ Add bookmark** to enter a title and URL.
   - **Reorder**: Drag rows using the `⋮⋮` handle or use the **▲** and **▼** buttons.
   - **Sort**: Tap **Sort A–Z** or **Sort Z–A** to order links alphabetically.
   - **Import**: Tap **Import bookmarks** to upload an exported `.html`, `.json`, or `.csv` bookmark file. Choose **Add to existing** or **Replace all**.
   - **Remove**: Tap **✕** next to any link to delete it.
4. Tap **Save**.

---

## Searching and Filtering

In the Bookmarks detail view:
- Use the **Search bookmarks…** input bar to filter links by name or URL in real time.
- Tap **✕** to clear the search query and restore the full list.
- Use the **A–Z** toggle in the header to view bookmarks in ascending or descending alphabetical order on the fly.
