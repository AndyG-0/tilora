# Game 2048 Widget

The **Game 2048** widget (`type: game2048`) brings the classic sliding number puzzle game directly onto your smart display or browser.

---

## Features

- **Touch and Keyboard Controls**: Swipe on touchscreens or use arrow keys on desktop.
- **Client-Side Storage**: Preserves current board state and personal high score in local browser storage.
- **Zero Configuration**: Works out of the box with zero external dependencies.

---

## Configuration (`dashboard.yaml`)

```yaml
- id: game2048
  type: game2048
  enabled: true
  layout: { col: 4, row: 3, colSpan: 1, rowSpan: 1 }
  settings: {}
```
