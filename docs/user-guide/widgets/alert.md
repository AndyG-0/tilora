# Alert Widget

The **Alert** widget (`type: alert`) displays important system notifications, user alerts, or warnings generated by the AI assistant across the dashboard.

---

## Features

- **Severity Indicators**: Supports `info` (blue), `warning` (amber), and `critical` (red) alert banners.
- **Dismissible Alerts**: Tap **Dismiss** on the tile or in the detail view to acknowledge and remove active alerts.
- **AI Tool Integration**: Exposes the `create_alert` tool to the voice assistant and scheduled AI jobs (e.g. *"Tilora, alert the household that the garage door is open"*).
- **REST API Triggering**: Can be triggered externally via simple HTTP requests (`POST /api/alerts`) from Home Assistant, curl, or custom scripts.

---

## Configuration (`dashboard.yaml`)

```yaml
- id: alert
  type: alert
  enabled: true
  layout: { col: 1, row: 8, colSpan: 4, rowSpan: 1 }
  settings: {}
```

---

## Triggering Alerts via API

```bash
curl -X POST http://<tilora-ip>:8000/api/alerts \
  -H "Content-Type: application/json" \
  -d '{"message": "Trash collection tomorrow morning!", "severity": "info"}'
```
